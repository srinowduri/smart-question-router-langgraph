general notes:

Gemini = the brain 🧠
LangGraph = the manager/project coordinator 📋

The brain knows how to think.

The manager decides:

Which task comes first?
Which worker should do the next task?
When is the work finished?

That's exactly what LangGraph does.

StateGraph is the main LangGraph object used to define an agent's workflow. It manages the shared state, nodes, and edges, and controls how data flows through the application from START to END.

A Tool is a capability that an AI agent can use to perform a specific task.

I built a LangGraph workflow where Gemini acts as the reasoning engine. LangGraph manages the workflow execution. The application maintains a shared state that flows between nodes. The intent detection node uses the LLM to classify the user's request, and conditional edges route the request either to a calculator tool or a general response node.
